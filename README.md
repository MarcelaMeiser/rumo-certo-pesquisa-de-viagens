# ✈️ Rumo Certo - Pesquisa de Viagens

> Sistema web para pesquisar e planejar as suas próximas viagens
> 
> **👩‍💻 Autora:** Marcela Philippe Meiser Lima

## 📌 Sobre o Projeto

Este projeto tem como objetivo desenvolver uma aplicação web para pesquisa e planeamento de roteiros de viagens. A solução é construída utilizando o ecossistema Java, fornecendo uma base robusta para a gestão de destinos e organização pessoal.

## 🎯 Objetivos

- Desenvolver um sistema web funcional para pesquisa de viagens.
- Criar uma API e infraestrutura de backend utilizando Java e Spring Boot.
- Estruturar a interface e visualização de dados com HTML.
- Gerir dependências e execução através do Maven.
