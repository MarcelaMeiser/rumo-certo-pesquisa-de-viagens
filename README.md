✈️ Rumo Certo - Pesquisa de Viagens

Sistema web para pesquisar e planejar suas próximas viagens
👩‍💻 Autora: Marcela Philippe Meiser Lima

📌 Sobre o Projeto

Este projeto tem como objetivo desenvolver uma aplicação web para pesquisa e planejamento de roteiros de viagens. A solução é construída utilizando o ecossistema Java, fornecendo uma base robusta para o gerenciamento de destinos e organização pessoal.

🎯 Objetivos

* Desenvolver um sistema web funcional para pesquisa de viagens.
* Criar uma API e infraestrutura de backend utilizando Java e Spring Boot.
* Estruturar a interface e visualização de dados com HTML.
* Gerenciar dependências e execução através do Maven.

🗂️ Organização do Projeto

📁 rumo-certo-pesquisa-de-viagens
│
├── 📁 src/main/java       → Código fonte, controladores e regras de negócio Java
├── 📁 src/main/resources  → Arquivos estáticos, templates HTML e configurações
├── 📄 pom.xml             → Arquivo de configuração de dependências do Maven
└── 📄 README.md           → Documentação do projeto

🛠️ Tecnologias Utilizadas

* Java
* Spring Boot
* HTML
* Maven

🔍 Etapas do Projeto

1️⃣ Estruturação
* Criação do repositório e configuração inicial do Maven.
* Estruturação de pacotes e definição do modelo de domínio das viagens.

2️⃣ Desenvolvimento Backend
* Configuração do Spring Boot.
* Criação dos endpoints para pesquisa e planejamento dos roteiros.

3️⃣ Interface Web
* Desenvolvimento das páginas e formulários em HTML.
* Integração das views com o backend em Java.

✅ Conclusão

O projeto "Rumo Certo" estabelece uma plataforma prática para estruturar viagens. Utilizando tecnologias consolidadas como Java e Spring Boot, a aplicação garante confiabilidade no processamento das pesquisas e agilidade na visualização das informações via HTML, facilitando o planejamento de roteiros para o usuário.

🚀 Como Executar

Clone este repositório:
git clone https://github.com/MarcelaMeiser/rumo-certo-pesquisa-de-viagens.git

Acesse o diretório:
cd rumo-certo-pesquisa-de-viagens

Compile e execute a aplicação:
./mvnw clean install
./mvnw spring-boot:run
